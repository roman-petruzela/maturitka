## **Typy pamětí:**

**RAM** (Random-Access-Memory ) = RWM (Read – write memory)

- číst / zapisovat

**ROM** (Read only memory) paměť jen pro čtení

- ROM

- PROM

- EPROM

- EEPROM

- FLASH (SD)

SAM – paměť se sekvenčním přístupem

CAM – asociativní paměť

## Dělení:

- dočasné – operační paměť, grafická Ram, Chache – L1, L2, L3 a HDD, registry procesoru

- permanentní – HDD, SSD, SHDD, Flash, optické disky (CD, DVD, BluRay)

Dělení operačních pamětí:

- typy patice

- rychlost (MHz)

- velikost (GB)

- počtu osazovaných pamětí (single, double (dual) channel)

- časování

- počtu stran

Dělení dle typu patice:

- desktopy

   - DDR5 DIMM

   - starší:

      - SDR

      - DDR SDRAM [1] - double-data-rate synchronous dynamic random access memory

      - DDR4 DIMM

      - RIMM (Rambus DRAM (RDRAM) ) - dnes již nepoužitelné [6]

porovnání pamětí:

- notebooky

   - DDR4 SO-DIMM

   - DDR5 SO-DIMM

- serverové

   - UDIMM DDR4 ECC (Error Correcting Code)

   - RDIMM

   - LRDIMM

   - NVDIMM (nalezeno 7.12.2021)
