Operační systém je základní software, který umožňuje počítači správně fungovat. Řídí hardware počítače a poskytuje platformu pro spouštění programů.

Historie operačních systémů sahá až do 50. let 20. století, kdy byly vyvíjeny první počítače. První operační systémy byly velmi jednoduché a byly navrženy pro konkrétní počítače.

V 60. letech 20. století začaly vznikat komplexnější operační systémy, které byly navrženy pro širší škálu počítačů. Mezi nejznámější operační systémy této doby patří Multics <u>(https://cs.wikipedia.org/wiki/Multics), který byl vyvinut v laboratořích Bell Labs, a Unix (https://cs.wikipedia.org/wiki/Unix), který byl vyvinut v laboratořích AT&T Bell</u> Laboratories.

V 70. letech 20. století se operační systémy začaly masivně rozšiřovat. První osobní počítače, jako byl Altair 8800 a Apple II, byly dodávány s operačními systémy, jako je CP/M <u>(https://cs.wikipedia.org/wiki/CP/M) a Apple DOS (https://en.wikipedia.org/wiki/Apple_DOS).</u>

V 80. letech 20. století se objevily první operační systémy pro osobní počítače s grafickým uživatelským rozhraním (GUI). První operační systém s GUI Xerox Star <u>(https://en.wikipedia.org/wiki/Xerox_Star) se příliš nerozšířil.Mezi nejznámější operační</u> systémy této doby patří Microsoft Windows, Macintosh OS a AmigaOS.

V 90. letech 20. století se operační systémy staly ještě komplexnějšími a funkčnějšími. Standardem se stal multitasking, podpora více uživatelů a bezpečnostní funkce.

V 21. století se operační systémy začaly přizpůsobovat novým technologiím, jako jsou mobilní zařízení a cloud computing. Mezi nejznámější operační systémy této doby patří iOS, Android a Linux.

Nejdůležitější milníky v historii operačních systémů 1956: GM-NAA I/O, první rozšířenější operační systém

1964: Multics, první operační systém s více uživateli

1969: Unix, první operační systém napsaný v jazyku C

1971: CP/M, první operační systém pro osobní počítače

1976: Apple DOS, první operační systém pro Macintosh

1984: Macintosh OS, první operační systém s grafickým uživatelským rozhraním (GUI)

1993: Windows 3.1, první operační systém pro osobní počítače s podporou síťového prohlížeče

2007: iPhone, první chytrý telefon s operačním systémem iOS

2008: Android, první operační systém pro mobilní zařízení s otevřeným zdrojem

2010: Windows 8, první operační systém pro osobní počítače s podporou dotykového ovládání

2013: macOS X Mavericks, první operační systém pro Mac s podporou cloud computingu

## Fenomén Linux

Linux je operační systém, který je založen na unixovém jádru. Byl vyvinut Linusem Torvaldsem v roce 1991 a je jedním z nejpopulárnějších operačních systémů na světě.

Linux je svobodný a otevřený operační systém, což znamená, že jeho zdrojový kód je veřejně dostupný. To umožňuje uživatelům a vývojářům Linux upravovat a vylepšovat.

Linux je multiplatformní operační systém, což znamená, že lze jej provozovat na různých typech hardwaru, včetně osobních počítačů, serverů, mobilních zařízení a embedded zařízení.

Mezi výhody operačního systému Linux patří:

- **Svobodný a otevřený:** Zdrojový kód Linuxu je veřejně dostupný, což umožňuje uživatelům a vývojářům Linux upravovat a vylepšovat.

- **Multiplatformní:** Linux lze provozovat na různých typech hardwaru.

- **Výkonný a stabilní:** Linux je výkonný a stabilní operační systém, který je často používán v serverovém prostředí.

- **Bezplatný:** Linux je k dispozici zdarma, což je velký rozdíl oproti komerčním operačním systémům, jako jsou Windows a macOS.

## Linuxové distribuce

Linuxová distribuce je sada softwarových balíčků, které jsou shromážděny a upraveny tak, aby mohly být použity jako operační systém. Distribuce Linuxu obvykle zahrnují jádro Linuxu, správce balíčků, grafické uživatelské rozhraní, řadu aplikací a další softwarové komponenty.

Zde jsou některé populární linuxové distribuce:

- **Ubuntu:** Ubuntu je jedna z nejpopulárnějších linuxových distribucí na světě. Je známá svou jednoduchostí a uživatelskou přívětivostí.

- **Debian:** Debian je další populární linuxová distribuce, která je známá svou stabilitou a bezpečností. Je to jedna z nejstarších linuxových distribucí a je základem pro mnoho dalších distribucí.

- **Linux Mint:** Linux Mint je populární distribuce, která je založena na Ubuntu. Je známá svým elegantním uživatelským rozhraním a širokou škálou podporovaných aplikací.

- **Red Hat Enterprise Linux:** Red Hat Enterprise Linux je distribuce Linuxu navržená pro podnikové prostředí. Je známá svou stabilitou, bezpečností a podporou.

- **Fedora:** Fedora je distribuce Linuxu, která je známá svou inovačností a zaměřením na komunitu. Je to distribuce, kterou vyvíjí společnost Red Hat, ale je k dispozici zdarma.

## Nejnovější trendy v oblasti operačních systémů

**Mobilní zařízení:** Operační systémy pro mobilní zařízení, jako je iOS a Android, jsou stále populárnější. Díky novým technologiím, jako jsou chytré hodinky a virtuální realita, se očekává, že popularita mobilních zařízení bude i nadále růst.

**Cloud computing:** Cloud computing se stále více rozšiřuje. Operační systémy jsou stále více přizpůsobovány cloudovým technologiím. Mezi cloud computing platformy patří například Google mail, Drop Box, Microsoft Azure, ChromeOS atd.

**Virtuální počítače:** Virtuální počítače jsou stále populárnější. Operační systémy jsou stále více podporují virtuální počítače.

**Umělá inteligence:** Umělá inteligence je stále více populární. Operační systémy stále více podporují umělou inteligenci (vyhledávání, překlad, asistenti, optimalizace výkonu) Operační systémy pro superpočítače <u>https://top500.org/</u>
