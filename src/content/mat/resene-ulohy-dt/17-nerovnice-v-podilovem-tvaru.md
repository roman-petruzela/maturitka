Pracovní tematické zařazení: Nerovnice v podílovém tvaru Řešení: a) Rychlejší než kompletní zápis metody rozvětvení ( pracovní název ), metody logických spojek ( pracovní název ) nebo metody nulových bodů je zde tato logická úvaha: Čitatel je kladný, takže aby vyšla hodnota celého zlomku záporně, musí být jmenovatel záporný, tedy 3 – x  <  0          3 < x          x > 3          x Є ( 3,  ∞ ) podmínky:  x ≠ 3 b) Rychlejší než kompletní zápis metody rozvětvení ( pracovní název ), metody logických spojek ( pracovní název ) nebo metody nulových bodů je zde tento postup: Po vytknutí čísla (–1) buď v čitateli nebo ve jmenovateli můžeme ve zlomku krátit a tím zjistíme, že hodnota zlomku je pro každé číslo x ( kromě x = 3 ) rovna (–1).
