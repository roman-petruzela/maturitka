<u>Příklady z maturitních testů Cermat-u ( základní úroveň ) – Obecná posloupnost</u>

1) První tři po sobě jdoucí členy posloupnosti jsou a1 = 36,  a2 = 12,  a3 = 4. Který vzorec pro n-tý člen posloupnosti je možné pro tyto členy použít ? A) an = 36 + 24<sup>- n</sup> B) an = 52 – 16n          C) an = 60 – 24n D) an = 108 * n          E) an = 36 * )<sup>n</sup> Ostrý maturitní test Cermat-u ( základní úroveň ) – podzim 2014, příklad č. 24 Body: 2                    Výsledek:  D

Pracovní tematické zařazení: Obecná posloupnost Řešení:

Vzorec musí platit pro všechny 3 zadané členy a1, a2, a3. Začít můžeme nejlépe členem a1. Pokud vyjde pravdivá rovnost, pokračujeme členem a2 atd. Pokud pro kterýkoli člen vyjde nepravdivá rovnost, vzorec je nesprávný.

A)  an = 36 + 24<sup>- n</sup> a1 = 36 + 24<sup>- 1</sup> 36 = 36 + 24<sup>- 1</sup> … nepravdivá rovnost B)  an = 52 – 16n           a1 = 52 – 16*1          36 = 36 an = 52 – 16n           a2 = 52 – 16*2          12 = 20 … nepravdivá rovnost C)  an = 60 – 24n           a1 = 60 – 24*1          36 = 36 an = 60 – 24n           a2 = 60 – 24*2           12 = 12 an = 60 – 24n           a3 = 60 – 24*3           4 = –12 … nepravdivá rovnost D)  an = 108 * n       a1 = 108 * 1         36 = 36 an = 108 * n        a2 = 108 * 2         a2 = 108 * 12 = 12 an = 108 * n        a3 = 108 * 3         a3 = 108 * 4 = 4 E)  an = 36 * )<sup>n</sup> a1 = 36 * )<sup>1</sup> 36 = 12 … nepravdivá rovnost

Pro tyto členy <u>je možné použít vzorec D.</u>
