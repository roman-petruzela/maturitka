Pracovní tematické zařazení: Slovní úlohy řešené pomocí rovnice nebo soustavy rovnic Řešení: ve 2. zaměstnání stráví týdně … x hodin ve 2. zaměstnání vydělá týdně … 300x Kč v 1. zaměstnání stráví týdně … ( x + 10 ) hodin v 1. zaměstnání vydělá týdně … 400( x + 10 ) Kč V 1. zaměstnání si týdně vydělá dvakrát více než ve 2. zaměstnání, takže týdenní výdělek v 1. zaměstnání  =  2 * týdenní výdělek ve 2. zaměstnání ( pozor !! – nikoli naopak ) 400( x + 10 )  =  2 * 300x          400x  +  4000  =  600x          4000  =  200x     20 = x v 1. zaměstnání stráví týdně … ( x + 10 ) hodin  =  30 hodin

Užitím rovnic vypočtěte, kolik korun se zaplatilo za meruňky. <u>Uveďte celý postup řešení.</u> Soubor vzorových úloh matematika ( vypracováno Cermatem v roce 2013 ), kapitola 3 – příklad č. 9 Body: neuvedeno                   Výsledek:  55 Kč

Pracovní tematické zařazení: Slovní úlohy řešené pomocí rovnice nebo soustavy rovnic Řešení: <u>1. způsob – pomocí rovnice</u> kilo meruněk … x Kč               kilo broskví … ( x – 2 ) Kč 2,5x + 1,5( x – 2 )  =  85               2,5x + 1,5x – 3  =  85               4x = 88 x = 22 ( kilo meruněk )                 2,5 * 22 Kč = 55 Kč <u>2. způsob – pomocí soustavy dvou rovnic o dvou neznámých</u> kilo meruněk … x Kč               kilo broskví … y Kč 2,5x + 1,5y  =  85 <u>y = x – 2   ( pozor !!! – nikoli  x = y – 2 )</u> dosazovací metoda … 2,5x + 1,5( x – 2 )  =  85          2,5x + 1,5x – 3  =  85          4x = 88 x = 22 ( kilo meruněk )               2,5 * 22 Kč = 55 Kč Poznámka: Soustavu je možné řešit několika dalšími způsoby, např. sčítací metodou.
