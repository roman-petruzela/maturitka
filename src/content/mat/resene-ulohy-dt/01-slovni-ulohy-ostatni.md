-------------------------------------------------8) V Kocourkově se příjmy obyvatel každým rokem zvýší o 50 % oproti příjmům z předchozího roku. Během každého dvouletého období však peníze ztratí polovinu své hodnoty. Jak se změní hodnota příjmů po uplynutí deseti let ? A) Zvýší se více než o 200 %.       B) Zvýší se přibližně o 80 %.       C) Nezmění se. D) <u>Sníží se přibližně o 69 %.         E) Sníží se přibližně o 94 %.</u> Ostrý maturitní test Cermat-u ( základní úroveň ) – podzim 2011, příklad č. 22 Body: 2                   Výsledek:  B

Pracovní tematické zařazení: Slovní úlohy ostatní Řešení: Počáteční příjmy … x Kč Příjmy po jednom roce … x + 50 % z x  =  x + 0,50x  =  1,50x  =  1,5x Příjmy po dvou letech … 1,5x + 50 % z 1,5x  =  1,5x  +  0,50 * 1,5x  =  1,5x + 0,75x  =  2,25x Ztráta poloviny hodnoty … 2,25x : 2  =  1,125x Částku, která vznikne z původní částky x po dvou letech, tedy získáme tak, že původní částku x vynásobíme číslem 1,125 Tato situace se opakuje každé 2 roky, takže za 10 let je výsledná částka … x * 1,125 * 1,125 * 1,125 * 1,125 * 1,125  =  x * 1,125<sup>5</sup> =  přibližně 1,80x Hned tedy vidíme, že dojde ( z částky x na částku 1,80x ) ke zvýšení o přibližně 80 %. jiný způsob: 100 % … x ( tedy hodnota původní, nikoli nová !!! ) 1 % … 0,01x Kolikrát se „vejde“ 1 % do výsledné částky 1,80x ? … 1,80x : 0,01x  =  180 ( procent ) Rozdíl … 180 % ( výsledná částka ) – 100 % ( <u>původní částka )  =  80 %</u>
