<u>Příklady z maturitních testů Cermat-u ( základní úroveň ) – Rovnice v součinovém nebo podílovém tvaru</u>

4(𝑦<sup>2</sup> + 1)(2𝑦 − 3) 1) Je dán výraz: 2𝑦 + 4 Určete množinu všech y ∈ R, <u>pro která má výraz hodnotu 0.</u> Ostrý maturitní test Cermat-u ( základní úroveň ) – jaro 2017, příklad č. 1 3 Body: 1                    Výsledek:  { <u>2 }</u>

Pracovní tematické zařazení: Rovnice v součinovém nebo podílovém tvaru Řešení: 4(𝑦<sup>2</sup> + 1)(2𝑦 − 3) =  0 2𝑦 + 4 Podíl je roven nule, když je čitatel roven nule a současně jmenovatel je různý od nuly. 4( y<sup>2</sup> + 1 )( 2y – 3 )  =  0 Součin je roven nule, když je alespoň jeden z činitelů roven nule, tedy y<sup>2</sup> + 1 = 0                          nebo          2y – 3 = 0 3 y<sup>2</sup> =  –1                                                y = 2 tato rovnice nemá řešení podmínky:  2y + 4 ≠ 0          y ≠ –2 3 Řešením rovnice je číslo <u>2</u>
