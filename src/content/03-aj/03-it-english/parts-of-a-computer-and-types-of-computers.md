## Hardware and software

A computer consists of **hardware** – the physical parts you can touch – and **software** – the programs. The most important piece of software is the **operating system** (Windows, macOS, Linux, Android, iOS), which controls the hardware and runs the **applications** (apps).

A computer works in four steps: **input** → **processing** → **storage** → **output**.

## Inside the computer

| Part | What it does |
| --- | --- |
| **motherboard** | the main circuit board that connects all the parts; it contains the **chipset**, slots and connectors |
| **processor (CPU)** | the "brain" of the computer – it carries out instructions; its speed is measured in **gigahertz** (GHz) and modern CPUs have several **cores** |
| **memory (RAM)** | fast temporary memory for the programs and data currently in use; it is **volatile** – its content is lost when the computer is switched off |
| **ROM / firmware (BIOS, UEFI)** | permanent memory with the program that starts the computer |
| **storage** | keeps data permanently: a **hard disk drive** (HDD) with spinning platters, or a faster, quieter **solid-state drive** (SSD) with flash memory |
| **graphics card (GPU)** | processes images and video; important for games, video editing and AI |
| **power supply unit (PSU)** | converts electricity from the socket for the components |
| **cooling** | fans or liquid cooling which stop the parts from overheating |
| **network card**, **sound card** | connect the computer to a network / process sound (often built into the motherboard) |

All these parts are inside the **case** (tower). Capacity of memory and storage is measured in **bytes** – kilobytes, megabytes, **gigabytes** (GB) and **terabytes** (TB).

## Peripherals

**Peripherals** are devices connected to the computer from outside, usually through **USB**, HDMI or wirelessly by Bluetooth or Wi-Fi.

- **Input devices:** keyboard, mouse, touchpad, touchscreen, microphone, webcam, scanner, game controller.
- **Output devices:** monitor, printer (inkjet or laser), speakers, headphones, projector.
- **Storage devices:** external hard drive, USB flash drive, memory card; more and more data is stored in **the cloud**.

## Types of computers

| Type | Description |
| --- | --- |
| **desktop computer** | a powerful computer for one place; easy to upgrade |
| **laptop / notebook** | a portable computer with a built-in screen, keyboard and battery |
| **tablet** | a flat device controlled by a touchscreen |
| **smartphone** | a mobile phone with the functions of a small computer |
| **wearables** | smartwatches and fitness bands |
| **server** | a powerful computer that provides services (websites, email, files) to other computers in a network |
| **workstation** | a very powerful computer for professionals – 3D design, video editing |
| **mainframe / supercomputer** | huge computers used by banks, scientists or for weather forecasts |
| **embedded systems** | small computers built into other devices – cars, washing machines, routers; with internet connection they form the **Internet of Things** (IoT) |

## Buying a computer

When you buy a computer, think about **what you will use it for**. For office work and school a cheaper laptop with an SSD and 16 GB of RAM is enough; for gaming or video editing you need a powerful processor and graphics card. You should also compare the **price**, **battery life**, **weight**, **screen size and resolution**, the **warranty** and **reviews**. You can buy it in a shop, where you can try it and get advice, or online, which is often cheaper – but you can return goods bought online within 14 days in the EU.

## Useful phrases

- *The main function of the… is to…*
- *It is used for… / It allows you to…*
- *The more RAM you have, the more programs you can run at the same time.*
- *An SSD is much faster than an HDD, but it is also more expensive.*
- *If I were buying a new computer, I would choose…, because…*
